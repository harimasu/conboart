CONBOART - How to run in terminal
==================================

EASIEST WAY
-----------
From the project root, run:

    run.bat

This will:
  - create/activate the .venv virtual environment (already present)
  - install backend dependencies
  - copy backend/.env.example to backend/.env if missing
  - start the server and open http://127.0.0.1:8000/ in your browser


MANUAL STEPS (PowerShell)
--------------------------
1. Activate the virtual environment:
     .venv\Scripts\activate

2. Install dependencies:
     pip install -r backend\requirements.txt

3. Make sure the env file exists (leave GENERATOR=mock to run offline,
   no fal.ai account needed):
     copy backend\.env.example backend\.env

4. Run the server:
     uvicorn backend.main:app --reload

5. Open in your browser:
     http://127.0.0.1:8000/


NOTES
-----
- MOCK mode: with GENERATOR=mock, the backend fabricates a sample model
  instead of calling fal.ai, so you can test the whole pipeline offline.
  Set GENERATOR=fal and add a FAL_KEY (https://fal.ai/dashboard/keys) to
  use real generation.
- Requires Python 3.10+.
