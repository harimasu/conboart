Why it exists

Traditional 3D modeling demands costly software, training, and technical skill — a real barrier for students, hobbyists, and beginners. CONBOART removes the manual work and the learning curve, so anyone can go from a picture to a printable model in a few clicks. Nothing is stored: each model lives only for your session.

Questions & formats

For 3D printing, choose STL — the universal printer format. For SketchUp, choose DAE. For general use with color, GLB is a solid all-rounder. CAD formats are available too, with a caveat noted below.

CONBOART can't write SketchUp's own .skp file directly, so you export a format SketchUp imports, then save it as .skp yourself:

Export as DAE (recommended — it keeps materials) or GLB. In SketchUp Pro or Studio, choose File → Import, then File → Save As → .skp.

Importing needs SketchUp Pro or Studio — the free web version won't import these. Avoid OBJ for SketchUp; it needs an extra plugin.

Yes, with one honest caveat. A model made from a photo is a triangle mesh, not parametric CAD. Exporting STEP or IGES — or importing an STL into Fusion or FreeCAD — brings it in as a dense faceted solid: usable for reference and basic edits, but not clean, editable CAD geometry. That limit comes from starting with a mesh.

It's a quick read on whether a model is likely to print cleanly. It checks that the mesh is watertight, has consistent surface normals, forms a single connected body, and has a valid volume. A warning doesn't always mean it won't print — just that it may need attention or supports.

One clear subject, a plain background, and even lighting. Front-facing objects with visible detail convert best. Busy backgrounds or multiple subjects tend to confuse the reconstruction.

No. CONBOART is per-session only — no gallery, no account. Your image and model exist just long enough to preview and download, then they're discarded.
